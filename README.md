# Replication Package: When Credit Expands Education

Replication package for:

**“When Credit Expands Education: Evidence from Thailand’s One Million Baht Village Fund”**

## 1. Software Requirements

The replication package was developed using **Stata 18.5** and tested on **Windows 11**.

## 2. Data Requirements

The following datasets cannot be redistributed with this repository:

* Townsend Thai annual household survey
* Townsend Thai key informant survey
* 2000 Socio-Economic Survey (SES)
* Gross provincial product (GPP) data

The **Townsend Thai annual household survey** and **Townsend Thai key informant survey** can be obtained from the Townsend Thai Project: https://townsend-thai.mit.edu/about/

The **2000 SES** data can be obtained from the Thai National Statistical Office.

The GPP data is distributed with the repository: data/99external_GPP_long.dta

Users must obtain these datasets separately and specify their locations in `do/00_master.do`.

The 2000 SES data are used only to produce summary statistics and calculate the EEG measure. They are therefore **not required to replicate the main analysis**.

## 3. Repository Structure

```text
.
├── README.md
├── do/
├── data/
├── out/
└── log/
```

* `do/` — Stata do-files
* `data/` — intermediate data
* `out/` — tables and figures generated by the replication code
* `log/` — log files generated during replication

## 4. Replication Procedure

Before running the replication code:

1. Obtain the required external datasets.
2. Specify the locations of the external datasets in `do/00_master.do`.
3. Install any required user-written Stata packages.
4. Run `do/00_master.do`.

The master do-file calls the analysis programs in the appropriate order.

## 5. Output

Running `00_master.do` reproduces the tables and figures reported in the paper.

Generated tables and figures are saved in the `out/` directory.
